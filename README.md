# نظام المرفق الواحد عبر QR ثابت

مشروع Node.js جاهز لفكرة:

- QR واحد ثابت لا يتغير.
- رفع مرفق جديد من لوحة الإدارة.
- أول شخص يمسح QR ويحصل على جلسة وصول.
- المرفق متاح لذلك الشخص لمدة 5 دقائق افتراضيًا.
- أي شخص آخر بعد أول مطالبة لا يستطيع فتح نفس الدورة.
- عند رفع مرفق جديد، يعاد تفعيل نفس QR.
- الملفات لا تكون داخل مجلد public ولا يمكن الوصول إليها مباشرة.
- قاعدة SQLite تسجل تاريخ الرفع والمطالبة والانتهاء.

## 1) المتطلبات

Node.js 18 أو أحدث.

## 2) التشغيل

انسخ `.env.example` إلى `.env` وعدّل القيم.

ثم:

```bash
npm install
npm start
```

افتح:

- لوحة الإدارة: `http://localhost:3001/admin`
- رابط QR الثابت: `http://localhost:3001/q`

بيانات الدخول الافتراضية من `.env`:
- المستخدم: `admin`
- كلمة المرور: غيّرها فورًا.

## 3) على شبكة داخلية

إذا كان الجهاز الذي يشغل الخادم عنوانه مثلًا `192.168.1.50`، اجعل:

```env
BASE_URL=http://192.168.1.50:3001
```

ثم اطبع QR من لوحة الإدارة.

الأجهزة الأخرى يجب أن تكون قادرة على الوصول إلى المنفذ 3001.

## 4) على الإنترنت

استخدم HTTPS عبر Nginx أو Cloudflare Tunnel أو Reverse Proxy، واجعل:

```env
BASE_URL=https://your-domain.example
```

ولا تعرض منفذ Node.js مباشرة إن كان الخادم عامًا.

## 5) سلوك النظام

الدورة تكون:

رفع `file-A.pdf`
→ QR ثابت = متاح
→ أول شخص يمسحه = claim
→ يحصل على 5 دقائق
→ الآخرون = غير متاح

ثم رفع `file-B.pdf`
→ تبدأ دورة جديدة
→ نفس QR = متاح مرة أخرى.

## 6) ملاحظات أمنية

هذا النظام يمنع الوصول الثاني من خلال الخادم، لكنه لا يستطيع منع المستخدم الأول من:
- تصوير الشاشة.
- حفظ نسخة من الملف.
- تصوير QR ومشاركته قبل استخدامه.

إذا كان المطلوب منع مشاركة QR أو معرفة هوية المستخدم، يمكن إضافة تسجيل دخول/OTP/رقم موظف قبل السماح بالوصول.

## 7) تغيير مدة الخمس دقائق

في `.env`:

```env
ACCESS_MINUTES=5
```

يمكن تغييرها إلى أي عدد دقائق.

## 8) أنواع الملفات

يمكن رفع PDF أو صور أو مستندات أو أي نوع يدعمه المتصفح للعرض. الأنواع التي لا يدعمها المتصفح قد تظهر كتنزيل/ملف بدلاً من المعاينة.

## 9) النسخ الاحتياطي

احتفظ بنسخة من:
- `data/app.db`
- `uploads/`

ولا تحذف `data/app.db` أثناء التشغيل.
